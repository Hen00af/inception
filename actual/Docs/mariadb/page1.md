# page1: MariaDB とは何か

## MariaDB の概要

MariaDB はリレーショナルデータベース管理システムである。  
データを表の形で保存し、SQL を使って読み書きする。

MySQL と互換性が高く、WordPress でも一般的に利用される。  
Inception では、WordPress の記事・ユーザー情報・設定値を保存する土台になる。

## Inception で必要になる理由

WordPress は PHP アプリケーションだが、情報をファイルだけでは管理しない。  
次のような情報はデータベースに保存される。

- 管理者ユーザー名
- 投稿データ
- コメント
- サイト設定
- プラグインやテーマが保存する設定値

つまり、MariaDB がなければ WordPress は動作しても中身を保持できない。

## 押さえるべき考え方

- Nginx は HTTP を受ける
- WordPress は PHP アプリケーションとして動く
- MariaDB は永続データを保持する

この 3 つは役割が違う。  
Inception の重要な学習ポイントは、役割ごとにコンテナを分けることにある。
