# FTP とは何か

## プロトコルとは

プロトコル = コンピュータ同士が通信するときの「約束事・ルール」のこと。

例えば：
- **HTTP** → ブラウザで Web ページを見るためのルール
- **SSH** → サーバーにリモートログインするためのルール
- **FTP** → ファイルを転送するためのルール

## FTP の役割

FTP (File Transfer Protocol) は、サーバーとクライアントの間でファイルを送受信するためのプロトコル。

```
自分の PC（FTP クライアント）
        ↕  ファイルのアップロード / ダウンロード
FTP サーバー（コンテナ）
        ↕  ファイルの読み書き
WordPress のファイル（ボリューム）
```

FTP クライアントとしては **FileZilla** が有名。GUI でファイルをドラッグ＆ドロップできる。

## なぜ Inception ボーナスで FTP を使うのか

WordPress のファイル（テーマ、プラグイン、画像など）は Docker ボリュームの中に保存されている。
コンテナの外からこのファイルに触れる手段として FTP サーバーを立てる。

FTP サーバーコンテナと WordPress コンテナは **同じボリュームをマウント** することでファイルを共有する。

```
FTP コンテナ      ─── /var/www/html (マウント) ───┐
                                                    ├── wordpress_data ボリューム
WordPress コンテナ ─── /var/www/html (マウント) ───┘
```

FTP で送ったファイルが、そのまま WordPress に反映される仕組み。

## ポート番号

FTP は通常 2 つのポートを使う：

| ポート | 用途 |
|--------|------|
| 21 | コマンドチャンネル（接続・認証・命令） |
| 20 or 高番号ポート | データチャンネル（実際のファイル転送） |
